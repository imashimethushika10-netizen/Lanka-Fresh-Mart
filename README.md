
# Lanka Fresh Mart - Sales Dashboard

## 1. Project Description

Lanka Fresh Mart Sales Dashboard is a responsive web application developed to display sales information in a clear and simple way.

The dashboard shows total revenue, total units sold, the best-performing month, and the best-performing branch. It also includes charts to visualize monthly revenue and branch revenue.

## 2. Objectives

- Display important sales information using KPI cards.
- Calculate sales summaries using JavaScript.
- Visualize monthly revenue using a line chart.
- Compare branch revenue using a bar chart.
- Create a responsive layout for desktop, tablet, and mobile devices.
- Provide a mobile navigation menu using a hamburger button.

## 3. Technologies Used

- HTML5 - To create the structure of the dashboard.
- CSS3 - To design the dashboard and make it responsive.
- JavaScript (ES6+) - To calculate sales values and control navigation.
- Chart.js - To create interactive charts.
- Font Awesome - To display icons.
- Google Fonts (Inter) - To style the text.

## 4. Project Files

- `index.html` - Contains the HTML structure of the dashboard.
- `style.css` - Contains the styles and responsive layout.
- `script.js` - Contains the sales data, calculations, navigation functions, and charts.
- `README.md` - Contains information about the project.

## 5. Dashboard Features

### KPI Cards

The dashboard contains four KPI cards:

1. Total Revenue
2. Total Units Sold
3. Best Month
4. Best Branch

The values are calculated dynamically using JavaScript.

### Charts

**Monthly Revenue Line Chart**

Displays monthly revenue from January to June 2026.

**Q2 Revenue by Branch Bar Chart**

Compares the revenue of Colombo, Kandy, and Galle branches.

### Responsive Design

- Desktop: Four KPI cards in one row and two charts side by side.
- Tablet: Two KPI cards per row.
- Mobile: One KPI card per row and charts stacked vertically.
- Mobile navigation: A hamburger button opens and closes the navigation menu.

## 7. How to Run the Project

1. Download or copy the project files into one folder.
2. Open the folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` using the Live Server extension.
5. View the dashboard in your web browser.
6. Resize the browser window to test the responsive design.

An internet connection is required to load Chart.js, Font Awesome, and Google Fonts from their CDNs.

## 8. Responsive Breakpoints

- Desktop: Above 1024px.
- Tablet: 769px to 1024px.
- Mobile: 768px and below.

CSS media queries are used to adjust the layout according to the screen size.

## 9. Conclusion

The Lanka Fresh Mart Sales Dashboard provides a simple and effective way to understand sales performance. It uses HTML, CSS, JavaScript, and Chart.js to present sales information through KPI cards and charts. The responsive design allows users to access the dashboard on desktop, tablet, and mobile devices.
